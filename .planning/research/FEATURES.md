# Feature Requirements & Dimensions

## 1. Table Stakes (Must Have)
- **보안 설정 로더 (.env)**:
  - `LMS_URL`, `LMS_USERNAME`, `LMS_PASSWORD`
  - `NOTION_API_KEY`, `NOTION_DATABASE_ID` (기본값: `21d53280-64be-80ec-af4e-000b679f03bb`)
  - `COURSE_MAPPINGS` (예: `{"공학수학2": "공수2", "자료구조": "자구", "디지털시스템설계": "디시설"}`)
- **LMS 헤드리스 브라우저 로그인 & 세션 유지**:
  - 사용자 계정 정보 기반 자동 로그인
  - 세션 쿠키/스토리지 상태 캐싱(`session.json`)으로 반복 로그인 최소화 및 속도 향상
- **수강 강의 목록 자동 수집**:
  - 현재 학기 수강 중인 전체 과목 이름 및 과목별 홈 URL 수집
- **주차별 온라인 강의 수강 현황 및 기한 파싱**:
  - 각 과목의 주차별 동영상/콘텐츠 목록
  - 수강 완료 여부 (출석/완료/진행중/미수강)
  - 수강 인정 마감 일시(Deadline)
- **과제 제출 여부 및 제출 마감일 파싱**:
  - 과제명, 제출 여부 (제출완료/미제출)
  - 과제 제출 마감 일시
- **마감 임박(24시간 이내) 감지 & 브리핑 출력**:
  - 미완료 강의 및 미제출 과제 중 마감 24시간 이내 항목 `[긴급 P1]` 태그 부여
  - CLI 터미널 및 에이전트 채팅에 요약 리포트 출력
- **Notion Scheduler 데이터베이스 연동**:
  - 대상 DB: `Scheduler` (`collection://21d53280-64be-80ec-af4e-000b679f03bb`)
  - **중복 등록 방지 로직**: DB 내 동일 작업 이름(`이름`) 또는 동일 DueDate의 기존 항목을 조회하여 중복 생성 방지
  - **통일된 이름 규칙 준수**: `[{과목약어}] {주차}주차 강의 시청`, `[{과목약어}] {과제명} 제출`
  - **정확한 속성 매핑**: `선택` (루틴/이벤트), `구분` (학업/과제/과목명), `DueDate`, `우선순위`, `상태` (시작 전)

## 2. Differentiators (Value-Add)
- **과목명 약칭 자동 정규화**:
  - 사용자가 노션에서 이미 사용 중인 규칙(`공수2`, `자구`, `디시설`)을 매핑 파일로 유연하게 관리하고 미지정 시 2~4글자 자동 축약 지원
- **선택적 동기화 모드**:
  - `--dry-run`: 노션에 등록하기 전 파싱된 데이터 및 등록 예정 목록을 미리 확인
  - `--only-pending`: 이미 수강 완료한 강의는 노션 등록에서 제외하고 미완료 항목만 등록
  - `--urgent-only`: 마감 임박 항목만 필터링하여 동기화
- **Antigravity AI Agent Skill 패키징**:
  - `SKILL.md`를 통해 에이전트가 `/check-courses`, `/sync-notion` 등의 자연어 요청을 받아 자동으로 스크립트를 실행하고 결과를 사용자에게 요약 브리핑

## 3. Anti-Features (Deliberately NOT Building)
- **강의 자동 재생 / 출석 대리 처리**:
  - 대학 학칙 위반 및 부정행위 방지를 위해 수강 상태 조회만 수행하며 자동 시청 기능은 절대 구현하지 않음.
- **2차 인증(OTP) 우회**:
  - 단순 ID/PW 기반 사이트를 1차 타깃으로 하며, 캡차나 OTP는 우회하지 않고 필요 시 브라우저 수동 로그인 세션 저장 모드로 유도.
- **중앙 서버형 다중 사용자 서비스**:
  - 사용자의 대학 포털 계정 정보를 보호하기 위해 외부 서버가 아닌 로컬 머신에서만 동작하는 독립형 에이전트 스킬로 한정.
