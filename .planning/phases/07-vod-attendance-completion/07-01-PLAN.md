<objective>
Parse real KAU LXP activity completion records and track VOD completion status.

Purpose: KAU LXP tracks student activity completion at `/report/ublogs/completion.php?id={course_id}` (`table-learning-student-activity`). Previously, the scraper visited a 404 URL and filtered out all lectures lacking an explicit `text-ubstrap` deadline, rendering all video lectures invisible. This plan hooks up the real completion page, merges completion status per VOD, and allows incomplete lectures to reach check/sync.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Hook up ublogs completion page in CourseNavigator and implement ublogs parser/merger</name>
  <files>src/kau_assistant/scraper/navigator.py, src/kau_assistant/scraper/lecture_parser.py, src/kau_assistant/pipeline.py</files>
  <action>
    1. In `src/kau_assistant/scraper/navigator.py`:
       - In `navigate_progress_page(page, course)`:
         - Navigate to `f"{base_url}/report/ublogs/completion.php?id={course.course_id}"`.
         - Wait for `.table-learning-student-activity, table.user_progress, .table-coursemos`.
         - If neither found or 404, fall back to `/report/ubcompletion/progress.php?id={course.course_id}`.
    2. In `src/kau_assistant/scraper/lecture_parser.py`:
       - Implement `parse_ublogs_completion(html: str) -> dict[str, AttendanceStatus]`:
         - Find `table.table-learning-student-activity` or table with headers containing "학습활동" / "완료 상태".
         - Extract rows:
           - Handle 4-column rows (`주차`, `학습활동명`, `완료 상태`, `완료 일시`) and 3-column rows (row-spanned `주차`).
           - If "완료" in status and "미완료" not in status -> `AttendanceStatus.COMPLETED`.
           - If "미완료" in status or status is empty -> `AttendanceStatus.INCOMPLETE`.
           - Normalize title whitespace and store in dict `title -> AttendanceStatus`.
       - Implement `merge_ublogs_completion(lectures: list[LectureItem], status_map: dict[str, AttendanceStatus]) -> list[LectureItem]`:
         - Match lecture `clip_title` against `status_map` (exact or normalized substring).
         - If matched, update `lecture.status = status_map[matched_title]`.
    3. In `src/kau_assistant/pipeline.py`:
       - In `scrape_course`:
         - If `progress_html` contains "table-learning-student-activity" or "완료 상태":
           - `status_map = parse_ublogs_completion(progress_html)`
           - `lectures = merge_ublogs_completion(lectures, status_map)`
         - Else continue using existing `parse_ubcompletion_progress`.
  </action>
  <verify>
    <automated>uv run pytest tests/test_lecture_parser.py</automated>
  </verify>
</task>

    3. Add unit tests in `tests/test_transformer.py`:
