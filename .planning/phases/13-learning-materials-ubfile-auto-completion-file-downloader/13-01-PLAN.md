# Plan 13-01: Learning Materials (ubfile) Auto-Completion & File Downloader

## Context & Objectives

Phase 13 delivers automated completion of unviewed course materials (`ubfile` and Moodle `resource`) on Coursemos LXP and an organized local hierarchical downloader for lecture documents (PDF, PPT, ZIP, HWP, DOCX, XLSX, etc.):
1. 미열람 상태의 `ubfile` 학습자료 페이지를 방문(열람)하여 LXP 진도율을 100% 완료 상태로 자동 갱신 (RES-01).
2. 첨부 파일을 과목명 및 주차별 계층 폴더(`downloads/<과목명>/W{주차}/`) 구조로 로컬에 다운로드 및 정리 (RES-02, D-13-01).
3. CLI 명령어 `coursepilot materials` (별칭 `files`) 및 `--course`, `--week`, `--output-dir`, `--no-download`, `--dry-run`, `--json` 옵션 지원 (D-13-05..D-13-08).
4. LXP 세션 인증 쿠키를 재사용하는 안전한 스트림/파일 다운로드 파이프라인 구축.

## Unresolved Edge Probe Assumptions

- **RES-01 Assumption:** Coursemos LXP activity completion for `ubfile` and `resource` modules triggers upon an authenticated HTTP GET request to `/mod/ubfile/view.php?id={cmid}` or `/mod/resource/view.php?id={cmid}` via Moodle's `completion_info->set_module_viewed()`. No JavaScript execution or heartbeat pings are required. If an instructor disables completion tracking or requires manual checkbox clicking, the HTTP visit returns 200/302 and completes gracefully without throwing.
- **RES-02 Assumption:** Lecture materials may be delivered via direct download (HTTP redirect to `/pluginfile.php/`) or embedded HTML viewers (iframe/download button). The downloader detects `Content-Type`: binary streams are saved directly, while `text/html` responses trigger parsing via `extract_pluginfile_url` to find and stream the underlying document. If an external URL or unsupported plugin is encountered, the downloader records status `FAILED` and preserves overall pipeline continuity.

       - Ensure `default_name` ends with inferred extension.

     - Replaces illegal filesystem characters `[<>:"/\\|?*\x00-\x1f]+` with `_`.
     - Collapses whitespace sequences into a single space.
     - Windows reserved stem check: if `Path(cleaned).stem.upper()` is in `_WINDOWS_RESERVED`, prefix with `_` (e.g. `CON.pdf` -> `_CON.pdf`).
     - Strips trailing dots and spaces (`.rstrip(". ")`).

     - Returns fallback `"downloaded_file"` if empty string results.
