<objective>
Implement the core VOD playback engine (`src/kau_assistant/player/vod_player.py`) to automate Coursemos Video.js video playback in background, maintain attendance heartbeats, handle modals, and monitor progress until completion.

Purpose: Solve the Coursemos limitation where videos cannot be fast-forwarded or speed-adjusted without a prior complete playthrough. This engine plays videos cleanly in background with audio muted and dialogs handled, providing a foundation for automated attendance fulfillment.
</objective>

<task type="auto">
  <name>Task 2: Implement VodPlayer automation engine and unit tests</name>
  <files>src/kau_assistant/player/vod_player.py, tests/test_vod_player.py</files>
  <action>
    1. In `src/kau_assistant/player/vod_player.py`:
       - Implement `VodPlayer`:
         - `play_vod(page: Page, vod_url: str, options: PlaybackOptions = PlaybackOptions(), on_progress: Callable[[PlaybackProgress], None] | None = None) -> PlaybackProgress`:
           - Register dialog handler `page.on("dialog", lambda d: d.accept())` to auto-confirm resume/alert popups.
           - `page.goto(vod_url, wait_until="domcontentloaded")`.
           - Wait for selector `video` (timeout 15s).
           - Set `v.muted = True` and trigger `v.play()`.
           - Also attempt clicking `.vjs-big-play-button` or `.vjs-play-control` if paused.
           - Poll every `options.poll_interval_seconds`:
             - Query video state: `duration`, `currentTime`, `paused`, `ended`.
             - If `paused` and not `ended`, re-trigger `v.play()`.
             - Compute `progress_percent = (currentTime / duration) * 100.0`.
             - Call `on_progress(progress)` if provided.
             - Break when `ended` is True or `currentTime >= max(0.0, duration - 2.0)`.
           - Return final `PlaybackProgress` marked `is_completed=True`.
           - Catch exceptions, recording `error_message` in progress.
    2. In `tests/test_vod_player.py`:
       - Unit tests using mock Page:
         - `test_vod_player_successful_play_to_completion`: verifies navigation, dialog hook, playback trigger, progress polling, and completion.
         - `test_vod_player_resumes_if_paused`: verifies auto-resume when paused during playback.
         - `test_vod_player_handles_missing_video_tag`: verifies graceful error handling when video selector times out.
  </action>
  <verify>
    <automated>uv run pytest tests/test_vod_player.py</automated>
  </verify>
