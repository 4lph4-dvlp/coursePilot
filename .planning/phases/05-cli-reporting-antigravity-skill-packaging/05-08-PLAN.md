<objective>
Close the code half of blocker G-05-2: target the KAU LXP by default and make an empty or unsupported LMS result loud instead of silent.

Purpose: the UAT found that `.env` had no LMS_URL, so the tool silently scraped the old LMS (https://lms.kau.ac.kr, 0 courses this term) and reported an empty success; the user never learned where it was looking. Scope decision A + B: default to https://lxp.kau.ac.kr, and for Coursemos-family schools make a 0-course result and a non-Coursemos site produce clear, structured, user-facing messages that point at LMS_URL and the term.
Output: `DEFAULT_LMS_URL` in config.py; `ReportNotice` + `notices` in the v1 contract with the `no_courses_found` notice built by the reporter and rendered in Rich; `UnsupportedLmsError` with a static safe message (raised by 05-07's course discovery); JSON_CONTRACT.md and tests updated.
Discretion choice (documented): a 0-course result keeps exit code 0 (a genuinely empty term is not a failure, and D-12 exit semantics are costly to change) but always carries the notice; a non-Coursemos site is fatal (exit 2). The notice text is a static string, following the Phase 5 precedent for the unconfigured-Notion notice, so no settings value can leak (D-14).
</objective>
