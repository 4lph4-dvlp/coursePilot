# Plan 02-01: Scraper Core Models, Course List Extractor, Page Navigator & Debug Snapshot

## Objective

Phase 2의 첫 번째 실행 계획(Wave 1)으로, 스크래핑에 필요한 고속 인메모리 파서 의존성(`beautifulsoup4`, `lxml`)을 추가하고, 스크래퍼 핵심 DTO 데이터 모델(`models.py`), 디버그 스냅샷 덤퍼(`debug_dump.py`), LMS 대시보드 강좌 목록 추출 및 과목명 정제기(`course_list.py`), 그리고 스마트 대기 및 폴백 네비게이터(`navigator.py`)를 구현하고 테스트 스위트를 구축합니다.

## Context & Decisions

- **D-01 (수강 대상 및 학기 필터링):** LMS 대시보드의 '진행 중' 필터 및 현재 학기(연도-학기) 텍스트를 기준으로 정규 수강 과목을 자동 판별하고 지난 학기나 만료 강좌는 제외합니다.
- **D-02 (과목명 문자열 정규식 분리):** 과목명 문자열에서 정규식을 적용하여 순수 과목명(분반 번호, 연도, 학기 표기 제거), 원본 전체 텍스트, 강좌 ID를 모두 분리하여 데이터 모델(`CourseItem`)에 저장합니다.
- **D-03 (접근 불가 강좌 격리 및 스킵):** 강좌 진입 시 '접근 권한 없음' 또는 '비공개 강좌'(403/리다이렉트) 발생 시 경고 로그를 남기고 해당 과목만 스킵 후 나머지 과목 수집을 중단 없이 계속 진행합니다.
- **D-04 (캐시된 과목 목록 주입 지원):** 항상 실시간으로 대시보드를 탐색하되, 디버깅 및 단위 테스트를 위해 사전 로드된 과목 목록 주입/로드를 지원합니다.
- **D-13 (2단계 페이지 탐색 전략):** 과목별 데이터 수집 시 '학습현황(진도표/출석부)' 및 '과제/퀴즈 모아보기' 전용 페이지를 우선 활용하고, 해당 뷰가 없는 과목은 메인 홈(주차별 섹션)으로 안전하게 폴백합니다.
- **D-14 (스마트 명시적 대기):** 동적 렌더링 대기 시 주요 컨테이너 셀렉터 출현 대기와 `domcontentloaded`를 결합한 스마트 명시적 대기(최대 15초)를 적용합니다.
- **D-15 (WAF 차단 방지 순차 탐색):** LMS 서버 부하 및 대학 WAF/IP 차단 방지를 위해 단일 페이지 순차 탐색 + 요청 간 미세 딜레이(0.2~0.5초)를 적용합니다.
- **D-16 (장애 시 디버그 스냅샷 자동 저장):** 파싱 실패나 타임아웃 발생 시 원인 분석을 위해 `.cache/debug/` 디렉터리에 실패 화면 스크린샷과 HTML 스냅샷을 자동 저장합니다.

### Security & Robustness Considerations

- **T-02-03 (디버그 덤프 내 민감정보 노출):** `.cache/debug/` 디렉터리는 `.gitignore`에 등록되어 외부 유출을 방지함.
