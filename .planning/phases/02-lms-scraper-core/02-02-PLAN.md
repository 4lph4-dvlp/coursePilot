# Plan 02-02: Lecture Progress Parser, Assessment Deep Parser & Resilient Date Parser

## Objective

Phase 2의 두 번째 실행 계획(Wave 2)으로, 동영상 강의의 주차 및 차시별 분할 추출, 출석 인정 마크 및 진도율 100% 하이브리드 완료 판정, 지연 강의 플래깅(SCRP-03), 과제/퀴즈/토론 등 모든 평가 항목의 상세 본문 및 첨부파일 메타데이터 추출, 제출 상태 판정(SCRP-04), 그리고 다중 정규식 기반 유연한 날짜 파서 및 일요일 폴백 모듈을 완성합니다.

## Context & Decisions

- **D-05 (출석 마크 & 진도율 하이브리드 판정):** 동영상 강의 완료 여부는 출석 인정 마크('O', 체크 아이콘)를 최우선 기준으로 판정하며, 마크가 없는 경우 진도율 100% 도달 여부를 보조로 확인합니다.
- **D-06 (과거 지연 강의 전수 추출):** 출석 인정 마감 기한이 이미 지난 과거 주차의 미수강 강의도 누락하지 않고 추출하며, 노션 스케줄러 연동 시 '지연' 태스크로 전달될 수 있도록 `is_overdue=True` 및 `AttendanceStatus.OVERDUE`를 부여합니다.
- **D-07 (주차 내 개별 차시 분할 추출):** 한 주차 내에 여러 개의 동영상 클립(1차시, 2차시 등)이 포함된 경우 개별 영상(차시) 단위로 분할 추출하여 정밀한 태스크 단위(`[공수2] 3주차 1차시 시청`)를 구성합니다.
- **D-08 (다중 패턴 날짜 파서 & 일요일 폴백):** 다양한 한국어/표준 날짜시간 문자열을 다중 정규식으로 유연하게 파싱하며, 실패 시 원본 문자열을 보존하고 해당 주차 일요일 23:59:59로 안전하게 폴백합니다.
- **D-09 (모든 마감 평가 활동 포괄 수집):** 일반 과제뿐만 아니라 마감일이 지정된 주차별 퀴즈, 온라인 시험, 토론 게시글 제출 등 모든 평가 활동을 수집합니다.
- **D-10 (제출 상태 정밀 판정):** 평가 항목 제출 상태는 '미제출(No attempt)' 및 '임시저장(Draft)'을 미완료 태스크로 판정하고, '제출 완료(Submitted)' 및 '채점 완료(Graded)'는 완료 처리합니다.
- **D-11 (과제 상세 본문 및 첨부파일 전수 추출):** 과제/평가 항목은 요약 목록 수집에 그치지 않고 상세 페이지에 진입하여 교수자 안내문 본문(HTML/Text) 및 첨부파일 메타데이터(`AttachmentMeta`)까지 전수 추출합니다.
- **D-12 (정규 마감일 및 지각 제출 마감일 병기):** 정규 마감일(Due Date)을 주 DueDate로 설정하고, 지각 제출 마감일(Cut-off)이 존재하면 `cutoff_date`에 분리 저장합니다.

### Task 02-02-01: Flexible Multi-Pattern Date Parser & Weekly Fallback (D-08)

<action>

   - 한국 표준시(`Asia/Seoul`) 타임존 상수 `KST` 선언.
   - 다중 정규식 패턴 세트 정의:
     - `YYYY-MM-DD HH:MM(:SS)?` (구분자 `.`, `-`, `/`, 요일 표기 `(금)` 선택적 포함)
     - `YYYY년 M월 D일 HH:MM` 및 `M월 D일 HH:MM`
     - `~ MM-DD HH:MM`
   - `parse_lms_date(date_str: str, fallback_week: int | None = None, term_start_date: datetime | None = None) -> tuple[datetime | None, bool]`:
     - 문자열 전처리 및 각 정규식 패턴 순차 매칭.
     - 매칭 성공 시 `(parsed_datetime, False)` 반환 (두 번째 인자는 fallback_applied 여부).
     - 모든 패턴 실패 시:
       - `fallback_week`와 `term_start_date`가 제공되면 해당 주차의 일요일 23:59:59 KST로 계산하여 `(fallback_dt, True)` 반환.
       - 계산 불가 시 `(None, False)` 반환하되 원본 문자열을 보존.
   - `is_past_deadline(due_date: datetime | None, now: datetime | None = None) -> bool`:
     - 현재 KST 시각 기준 마감 경과 여부 판별.

   - 한국어 형식 날짜 문자열(`2026년 9월 25일 23:59`) 파싱.
   - 파싱 불가능한 텍스트 입력 시 주차 기준 일요일 23:59:59 폴백 생성 여부.
   - 마감일 경과(`is_past_deadline`) 판정 정확도.
