# Plan 01-02: Playwright Session Manager & LMS Authentication

## Objective

Phase 1의 두 번째 실행 계획(Wave 2)으로, Playwright 기반의 브라우저 라이프사이클 관리자(`session_manager.py`)와 다중 셀렉터 폴백 전략을 갖춘 LMS 인증 모듈(`auth.py`)을 구현합니다. 세션 쿠키 캐싱(`.cache/session.json`), 세션 만료 판별 및 자동 재로그인(Auto-healing), 30초 타임아웃 및 1회 자동 재시도 로직을 완성합니다.

## Context & Decisions

- **D-01 (커스텀 LMS URL 직접 접근):** LMS 로그인 페이지 URL은 설정 객체(`settings.lms_url`)를 통해 동적으로 주입되어 다양한 환경(코스모스/Canvas 등)에 유연하게 대응합니다.
- **D-03 (세션 캐시 파일 영속화):** Playwright의 `storage_state`는 `.cache/session.json`에 저장하고, 재실행 시 우선 로드하여 불필요한 반복 로그인을 방지합니다.
- **D-04 (세션 만료 판별 및 자동 재로그인):** 대시보드 접근 시 `login` URL로 리다이렉트되거나 인증 확인 셀렉터가 발견되지 않으면 세션 만료로 판정하고, 손상/만료된 캐시를 삭제 후 즉시 자동 재로그인하여 새 세션을 갱신합니다.
- **D-07 (헤드리스 기본 & 디버깅 모드 지원):** 브라우저는 기본적으로 Headless 모드로 구동하되, CLI 플래그(`--headful`) 및 환경변수(`HEADLESS=false`)를 통해 브라우저 화면 표시를 지원합니다.
- **D-08 (30초 타임아웃 & 1회 자동 재시도):** 기본 페이지 이동 및 네비게이션 타임아웃을 30초(`30000ms`)로 설정하고 일시적 지연 시 2초 백오프 후 1회 자동 재시도합니다.

## Must Haves

- `uv run pytest tests/test_auth.py tests/test_session_manager.py` 명령어가 100% 성공(Green) 통과해야 한다.

### Task 01-02-01: LMS Authentication Engine with Cascading Multi-Selectors (SCRP-01)

<action>
1. **D-01**, **D-07** 결정 및 리서치 패턴 1을 반영하여 `src/coursepilot/auth.py`를 구현합니다:
   - 셀렉터 그룹 정의:
     - `USERNAME_SELECTORS`: `["#input-username", "#pseudonym_session_unique_id", "input[name='username']", "input[name='pseudonym_session[unique_id]']", "#username"]`
     - `PASSWORD_SELECTORS`: `["#input-password", "#pseudonym_session_password", "input[name='password']", "input[name='pseudonym_session[password]']", "#password"]`
     - `SUBMIT_SELECTORS`: `["input[name='loginbutton']", "input[type='submit'].btn-success", "button[type='submit']", ".Button--login"]`
     - `LOGGED_IN_SELECTORS`: `[".usermenu", "a[href*='logout']", "#global_nav_profile_link", ".ic-app-header", ".block_coursemos_my_courses", ".my-course", "#dashboard"]`
   - `find_first_visible(page: Page, selectors: list[str], timeout: int = 5000) -> str | None`: 우선순위 리스트를 순회하며 화면에 노출된 첫 번째 셀렉터를 반환.
   - `perform_login(page: Page, username: str, password: str, lms_url: str, timeout_ms: int = 30000) -> None`:
     - 지정된 `lms_url`로 이동.
     - 다중 셀렉터로 사용자명, 패스워드, 제출 버튼을 탐색 (없을 시 `AuthenticationError` 발생).
     - 자격증명 입력 후 제출 버튼 클릭 및 로딩 대기.
     - 현재 URL에 `login`이 포함되어 있거나 에러 박스(`.alert-danger`, `.loginerrors`, `#flash_error_message`)가 보이면 에러 메시지를 추출하여 `AuthenticationError` 발생.
     - `LOGGED_IN_SELECTORS`를 통해 대시보드 진입을 최종 확인 (실패 시 `AuthenticationError` 발생).

   - 잘못된 자격증명으로 인한 에러 메시지 검출 및 `AuthenticationError` 발생
   - 로그인 후 대시보드 진입 요소 미검출 시 `AuthenticationError` 발생

### Task 01-02-02: Playwright Session Manager with Cache Invalidation, Auto-Healing & Retry (CONF-03, SCRP-01)

<action>
1. **D-03**, **D-04**, **D-07**, **D-08** 결정 및 리서치 패턴 2, 3을 반영하여 `src/coursepilot/session_manager.py`를 구현합니다:
   - `SessionManager` 클래스 구현:
     - `__init__(settings: Settings | None = None, headful: bool = False)`: `headful` 플래그 및 `settings.headless`에 따라 브라우저 헤드리스 여부 결정 (**D-07**).
     - 컨텍스트 매니저 인터페이스(`__enter__`, `__exit__`)로 `Playwright`, `Browser`, `BrowserContext`의 안전한 시작과 역순 종료 보장.
     - `_is_valid_cache_file(path: Path) -> bool`: 파일 존재 여부, 크기(> 2바이트), JSON 스키마(`cookies` 또는 `origins` 포함) 유효성 사전 검증으로 손상 파일 대응.
     - `_navigate_with_retry(page: Page, url: str) -> None`: 30초 타임아웃으로 페이지 이동을 시도하되, 실패 시 2초 대기 후 1회 재시도. 최종 실패 시 `NavigationTimeoutError` 발생 (**D-08**).
     - `_check_authenticated(page: Page) -> bool`: 현재 URL에 `login`이 포함되어 있거나 `LOGGED_IN_SELECTORS`가 없으면 `False` 반환 (**D-04**).
     - `get_authenticated_page() -> Page`:
       - `.cache/session.json` 캐시 파일이 유효하면 `storage_state` 옵션과 함께 브라우저 컨텍스트 생성 (**D-03**).
       - 표준 User-Agent, 뷰포트(1280x800), 한국어 로케일(`ko-KR`, timezone `Asia/Seoul`) 주입.
       - 대시보드로 이동하여 `_check_authenticated` 검사.
       - 세션이 유효하면 즉시 페이지 반환 (로그인 스킵).
       - 세션이 만료되었거나 캐시가 없으면: 만료된 캐시 파일 삭제 -> `perform_login()` 실행 -> 성공 후 `context.storage_state(path=...)`로 새 세션을 `.cache/session.json`에 저장 -> 인증된 페이지 반환 (**D-03**, **D-04**).
2. `tests/test_session_manager.py`를 작성하여 다음 시나리오를 검증합니다:
   - 유효한 캐시가 있을 때: 로그인 호출 없이 기존 세션 재사용
   - 만료된 세션일 때: 캐시 삭제 후 자동 재로그인 및 새 세션 저장 수행
   - 손상된(0바이트 또는 잘못된 JSON) 캐시일 때: 에러 없이 파일 무시/삭제 후 새 로그인 수행
   - 일시적 네비게이션 실패 시 1회 재시도 동작 및 최종 실패 시 `NavigationTimeoutError` 발생
   - 컨텍스트 매니저 종료 시 리소스 정상 반환
</action>
