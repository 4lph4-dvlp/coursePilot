# Plan 01-01: Project Scaffold, Configuration, Course Mapping & Test Infrastructure

## Objective

Phase 1의 첫 번째 실행 계획(Wave 1)으로, `uv` 및 `pyproject.toml` 기반의 표준 Python 패키징 환경을 구성하고, 타입 안전한 환경설정 로더(`config.py`)와 독립된 과목명 축약 매핑 로더(`course_mapping.py`) 및 단위 테스트 기반을 구축합니다.

## Context & Decisions

- **D-01 (LMS URL 설정 유연성):** LMS 접속 URL은 `.env`의 `LMS_URL`을 통해 커스텀 URL로 직접 접근하며 유연하게 변경 가능하도록 Pydantic 설정 모델에 바인딩합니다.
- **D-02 (uv & pyproject.toml 기반 패키징):** Python 패키징 및 의존성 관리는 `pyproject.toml` 및 `uv`를 기본 도구로 채택하여 고속 가상환경 생성 및 의존성 락을 보장합니다.
- **D-03 (개인정보 및 세션 격리):** `.gitignore`에 `.env` 및 `.cache/session.json`을 등록하여 자격증명과 세션 쿠키가 Git에 커밋되지 않도록 격리합니다.
- **D-05 (독립 과목명 매핑 JSON):** 과목명 축약 매핑은 `config/course_mappings.json` 독립 JSON 파일로 관리하여 사용자가 손쉽게 편집할 수 있도록 분리합니다.
- **D-06 (미매핑 과목 Fallback 및 안내):** 매핑 파일에 등록되지 않은 신규 과목이 감지될 경우 파싱 에러를 내지 않고 원본 과목명 그대로 사용하며 축약어 등록 권장 친절한 안내 로그를 출력합니다.

### Task 01-01-02: Decoupled Course Name Mapping with Fallback & Guidance (CONF-02)

<action>
1. **D-05** 결정에 따라 `config/course_mappings.json` 파일을 생성하고 초기 매핑 샘플을 등록합니다:
   ```json
   {
     "공학수학2": "공수2",
     "자료구조": "자구",
     "디지털시스템설계": "디시설"
   }
   ```
2. **D-06** 결정에 따라 `src/kau_assistant/course_mapping.py`를 구현합니다:
   - `load_course_mappings(path: Path | str = "config/course_mappings.json") -> dict[str, str]`: 파일이 없거나 JSON 파싱 실패 시 기본 fallback 딕셔너리를 반환하고 경고 로그를 남깁니다.
   - `get_abbreviation(course_name: str, mappings: dict[str, str]) -> str`:
     - 앞뒤 공백을 제거한 과목명이 `mappings`에 존재하면 약칭 반환.
     - 매핑되지 않은 신규 과목인 경우 `KeyError`를 발생시키지 않고 원본 과목명을 그대로 반환하며, `config/course_mappings.json` 등록을 권장하는 친절한 정보 로그(`logger.info`)를 출력.
3. `tests/test_course_mapping.py`를 작성하여 아래 시나리오를 검증합니다:
   - 정상 매핑 케이스 (`공학수학2` -> `공수2`)
   - 공백 포함 케이스 (`  자료구조  ` -> `자구`)
   - 미등록 신규 과목 케이스 (`신규과목A` -> `신규과목A` 반환 및 안내 로그 발생 확인)
   - 매핑 파일 누락 또는 손상 케이스 (기본 매핑 fallback 동작 확인)
