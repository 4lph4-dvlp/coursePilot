# Phase 16.1 Plan 02 Summary

Added a standalone `notion-scheduler` CLI for listing, previewing, creating, updating, and completing general Scheduler tasks. Every command emits versioned JSON. Write commands preview by default and require `--apply` to execute. The agent skill defaults to the direct API, documents optional official remote MCP use, and excludes delete/archive. The wheel packages both skill documents, and the README describes user-level installation.
