# Phase 16.1 Plan 03: CoursePilot Adapter and API/MCP Comparison Summary

CoursePilot now delegates Notion transport and the shared Scheduler schema to the sibling package while keeping LMS matching, sync planning, protected fields, and VOD completion behavior. Its JSON CLI shapes remain unchanged. The direct API is the default; official remote MCP is documented as an optional interactive path.

## Accomplishments

- Replaced CoursePilot's direct `notion-client` calls with a compatibility facade over `notion_scheduler.NotionClient`; preserved the 90-day-or-incomplete filter with cursor pagination and CoursePilot error types.
- Used the shared package schema/parser/serializer while retaining CoursePilot's academic category and priority mapping. Automatic updates still omit `Plan` and `상태`; explicit watch completion still writes `상태=완료`.
- Ran one read observation on the personal Scheduler and user-approved create/update observations on an isolated temporary Scheduler database. Both paths produced the same final task values. The temporary database was verified as `in_trash=true` after the experiment.
- Corrected the standalone CLI's Windows legacy-encoding output failure found during the live preview. Added compact task-list filters to control agent-visible JSON size.

## Verification

- CoursePilot Notion/watch targeted tests: 40 passed. Final full CoursePilot suite: passed.
- Standalone suite: 28 passed; wheel build succeeded; skill validation passed.
- Benchmark JSON validator: passed with all six workloads measured and the live-write approval, target, page IDs, and cleanup recorded.
- Production commits: CoursePilot `fa3138d` and clock-fixture `a0ca219`; sibling `ec629d8`, `76d06ae`, and `e15c7a7`.

## Limits

- Model-token usage counters were unavailable on both paths. The read and write timings use different process and tool boundaries; they are observations, not a normalized speed comparison.
- The local CoursePilot uv configuration requires the sibling `../notion-scheduler` checkout. Publishing or pinning a remote package source is a separate distribution step.
- Existing user edits in `src/coursepilot/installer.py` and `src/coursepilot/player/runner.py` were not changed.
