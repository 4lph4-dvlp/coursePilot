### 3. 주차 정보가 없는 과제/평가 항목의 처리

| Option | Description | Selected |
|--------|-------------|----------|
| 조건부 생략 | 주차 정보가 있으면 `{N}주차`를 포함하고, 특정 주차가 없는 공통/전체 과제는 주차 없이 `[과목약어] {과제명} 제출`로 유연하게 처리 | ✓ |
| 학기 시작일 기준 역산 | 과제 마감일자를 기준으로 학기 개강 주차를 자동 계산하여 `{N}주차`를 반드시 부여 | |
| [공통] 태그 표기 | 특정 주차가 없는 항목은 `[과목약어] [공통] {과제명} 제출`로 명시적 표기 | |

**User's choice:** 조건부 생략
**Notes:** 중간고사 대체 과제나 텀프로젝트 등 주차가 없는 과제는 깔끔하게 주차를 생략하고 원본 과제명으로 유연하게 폴백.

## 우선순위 및 속성 매핑

**Notes:** 학기 중 주기적으로 반복되는 인강과 일회성 마감 활동의 자연스러운 분리.

### 2. 노션 '우선순위'(P1~P4) 자동 배정 규칙

| Option | Description | Selected |
|--------|-------------|----------|
| 잔여 마감 시간 기반 계층화 | 24시간 이내 = P1, 3일 이내 = P2, 3일 초과 = P3, 기한 초과 = P4 | |
| 활동 유형 + 긴급도 결합형 | 24시간 이내 = 무조건 P1 승격, 평상시에는 과제/시험 = P2, 동영상 강의 = P3, 기한 초과 = P4 | ✓ |
| 단순 2단계형 | 24시간 이내만 P1으로 지정하고, 그 외 모든 미완료 항목은 P3(기본)으로 통일 | |

**User's choice:** 활동 유형 + 긴급도 결합형
**Notes:** 과제의 학업 비중(P2)과 강의(P3)를 차등화하되, 24시간 임박 시 최우선 순위(P1)로 승격.

### 3. 노션 'DueDate' 필드 기록 포맷

| Option | Description | Selected |

### 4. 노션 'Plan'(계획일) 및 '구분'(Multi-select) 속성 초기값

| Option | Description | Selected |
|--------|-------------|----------|

**Notes:** 개인 일정 계획의 자율성 보장.

### 3. 작업명 내 '지연' 태그 표기 여부

| Option | Description | Selected |
|--------|-------------|----------|

**Notes:** 사용자가 이미 Notion DB 내 `D-Day` 속성에서 오늘 날짜와 DueDate를 기반으로 지연 여부를 자동 계산하므로, 제목에 중복 태그를 붙이지 않고 깨끗한 표준 제목을 유지하기로 결정.

### 4. 마감일 없는 영상 및 설명란 기한 과제 처리
