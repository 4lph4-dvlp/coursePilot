# Plan 03-01: Domain Modeling, Task Naming Engine, Priority Analyzer & DTO Transformer

## Objective

Phase 3의 핵심 계획으로, Phase 2에서 수집된 스크래퍼 DTO(`CourseItem`, `LectureItem`, `AssessmentItem`)를 사용자의 개인 Notion Scheduler DB(`21d53280-64be-80ec-af4e-000b679f03bb`) 규격에 부합하는 비즈니스 도메인 모델(`SyncTask`, `Course`)로 변환·정규화하는 **순수 도메인 계층(Pure Domain Layer)**을 구축합니다.
사용자의 기존 노션 관례에 맞춘 정규화된 작업명 포매터(`naming.py`), 24시간 마감 임박 판정 및 우선순위 분석기(`priority.py`), 그리고 설명란 마감일 구출 및 1500자 안전 절삭 메모를 생성하는 DTO 변환기(`transformer.py`)를 구현하고 포괄적인 단위 테스트로 검증합니다.

## Context & Decisions

- **D-01 (동영상 강의 고정 차시 네이밍):** 온라인 동영상 강의는 고정 차시 표기형 `[{과목약어}] {N}주차 {M}차시 강의 시청` 포맷을 적용 (예: `[공수2] 3주차 1차시 강의 시청`).
- **D-02 (과제/평가 동사 분기 네이밍):** 활동 유형별 분기 포맷 적용: 일반 과제는 `[{과목약어}] {N}주차 {과제명} 제출`, 퀴즈/시험은 `[{과목약어}] {N}주차 [퀴즈] {이름} 응시`, 토론은 `[{과목약어}] {N}주차 [토론] {이름} 참여`.
- **D-03 (비주차 과제 폴백):** 주차 정보가 없는 공통/전체 과제는 주차 표기를 생략하여 `[{과목약어}] {과제명} 제출`로 조건부 폴백.
- **D-04 (스마트 제목 정제):** HTML 엔티티(`&amp;` -> `&` 등) 디코딩, 다중 공백 단일화, 교수자가 기재한 `[과제]` 등 중복 태그 및 접미사 동사(`제출 제출` 등) 방지 정제.
- **D-05 (노션 '선택' 속성 매핑):** 동영상 강의는 `루틴` (`TaskSelect.ROUTINE`), 과제/퀴즈/시험/토론은 `이벤트` (`TaskSelect.EVENT`)로 분류.
- **D-06 (노션 '우선순위' P1~P4 판정):**
  - 마감 24시간 이내 미완료: 무조건 `P1` (🔴 긴급)
  - 평상시 과제/시험/토론: `P2` (🟠 보통/높음)
  - 평상시 동영상 강의: `P3` (🟡 보통)
  - 마감 기한이 지난 항목(지연) 및 완료 항목: `P4` (⚪ 낮음)
- **D-07 (노션 'DueDate' KST 강제):** 한국 표준시(KST, UTC+9) 기준 `ensure_kst` validator를 적용하여 타임존 오차 차단.
- **D-08 (노션 'Plan' 및 '구분' 기본값):** `Plan`은 `None`으로 비워두어 사용자 직접 스케줄링 지원, `구분`은 `["학업"]`으로 자동 설정.
- **D-09 (미완료 항목 기본 선별):** 동기화 변환 함수 `transform_to_sync_tasks()`는 미완료 항목만 기본 반환 (`include_completed=False`), 모델 자체에는 `is_completed: bool` 필드 포함.
- **D-10 (과거 지연 항목 노션 상태):** 마감 지난 미완료 항목도 노션 상태(`상태`)는 `시작 전` (`TaskStatus.NOT_STARTED`)을 유지하며 제목에 `[지연]` 태그를 붙이지 않음 (노션 D-Day 수식 존중).
- **D-11 (마감일 없는 강의 제외 및 설명란 기한 구출):** 마감일 없는 상시/OT 영상은 스케줄러 동기화 대상에서 제외. LMS 기한 설정이 없더라도 과제 설명란에 제출 안내가 적혀 있는 과제는 본문 텍스트 정규식 분석으로 유효 마감일 구출.
- **D-12 (동영상 강의 노션 메모):** `LMS 바로가기: {link}` 형태로 단독/간결하게 구성.
- **D-13 (과제/평가 노션 메모 구조화):** LMS 바로가기 링크, 지각 제출 마감일, 첨부파일 목록, 교수자 과제 설명 단락별 구조화.
- **D-14 (1500자/1950자 안전 절삭):** 노션 API 2000자 제한 방어를 위해 설명문 1500자 초과 시 절삭(`\n... [이하 생략 - 전체 내용은 LMS 페이지 참조]`), 전체 메모 1950자 상한 하드캡 적용.
- **D-15 (도메인 서브패키지 모듈화):** `src/kau_assistant/domain/` 서브패키지에 `models.py`, `naming.py`, `priority.py`, `transformer.py`, `__init__.py`로 모듈 분리.
