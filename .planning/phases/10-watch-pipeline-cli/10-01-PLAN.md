<objective>
Build the watch pipeline and CLI runner (`coursepilot watch`) to filter incomplete VODs by course and week, execute sequential background playback via `VodPlayer`, and optionally mark completed tasks as '완료' in Notion Scheduler.

Purpose: Allow students and AI agents to trigger automated attendance fulfillment for specific courses and weeks with a single command (e.g. `coursepilot watch --course "기초전자실험" --week current --update-notion`).
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Implement watch_course_vods runner and Notion completion updater</name>
  <files>src/coursepilot/player/runner.py, src/coursepilot/notion/client.py</files>
  <action>
    1. In `src/coursepilot/notion/client.py`:
       - Add `mark_task_completed(page_id: str) -> None`:
         - Calls `self.update_page(page_id, {"상태": {"status": {"name": "완료"}}})`.
    2. In `src/coursepilot/player/runner.py`:
       - Define `WatchResult` model:
         - `course_name: str`
         - `course_id: str`
         - `target_week: str`
         - `total_vods: int`
         - `completed_vods: int`
         - `skipped_vods: int`
         - `playback_results: list[PlaybackProgress]`
         - `notion_updated_count: int`
       - Implement `watch_course_vods(...)`:
         - Loads settings and gets authenticated Page.
         - Discovers courses via `extract_courses` and finds matching course by query (fuzzy/exact match against clean_name, raw_name, course_id, or mappings).
         - Scrapes course via `scrape_course(page, course, navigator)`.
         - Resolves target week:
           - If `week == "current"`: find earliest incomplete regular week (or week with earliest upcoming deadline).
           - If `week == "all"`: all incomplete weeks.
           - If integer string (e.g. "4"): that specific week.
         - Filters candidate VODs:
           - `v.status == AttendanceStatus.INCOMPLETE`
           - `"/mod/vod/" in v.link`
           - Not OT/orientation video (`v.week_number > 0`)
         - If dry_run: returns planned VODs without playback.
         - For each candidate VOD:
           - Plays via `VodPlayer.play_vod(page, vod.link, title=vod.full_title, ...)`.
           - If `update_notion` and playback succeeded:
             - Resolve Notion page by task title (`format_task_title(...)`).
             - Call `client.mark_task_completed(page.id)`.
         - Return `WatchResult`.
  </action>
  <verify>
    <automated>uv run python -c "from coursepilot.player.runner import watch_course_vods; print('Runner OK')"</automated>
  </verify>
</task>
