# Plan 14-01: Pure-Python HLS Manifest Parser, RFC 8216 AES-128 Decryptor & Atomic TS Downloader Engine

## Context & Objectives

Phase 14 delivers a pure-Python, zero-external-binary HLS/m3u8 streaming, decryption, and segment assembly engine for KAU LXP lecture videos (VDL-01):
1. 의존성 관리: `m3u8>=6.0.0`, `cryptography>=50.0.0`, `httpx>=0.28.0`을 프로젝트 런타임 의존성에 추가.
2. 도메인 모델 정의: 스트림 메타데이터, 화질 변형, 암호화 키, 세그먼트, 다운로드 진행률 및 실행 결과를 표현하는 Pydantic 모델 구축.
3. 암호화 처리: RFC 8216 규격을 엄격히 준수하는 AES-128-CBC 복호화, 시퀀스 번호 기반 묵시적 IV(implicit IV) 유도, 비표준 패딩에 대한 내결함성 fallback 구현.
4. M3U8 파싱: 다중 비트레이트 마스터 플레이리스트에서 선호 화질(`best`, `1080p`, `720p`, `worst`) 자동 선택 및 미디어 플레이리스트 세그먼트/키 파서 구현.
5. 고속 다운로더: `httpx` 및 `ThreadPoolExecutor` 기반 세그먼트 병렬 다운로드, 인메모리 키 캐싱, 3회 지수 백오프 재시도, 순수 바이너리 순차 결합 및 원자적 `.mp4` 저장 구현.

## Artifacts this phase produces

This plan creates the core streaming engine components (other components created in Plan 14-02 are listed for architectural clarity):
- `pyproject.toml` (14-01): Adds `"m3u8>=6.0.0"`, `"cryptography>=50.0.0"`, `"httpx>=0.28.0"`.

- `src/coursepilot/stream/crypto.py` (14-01): Functions `derive_implicit_iv(sequence_number: int) -> bytes`, `decrypt_aes_128_segment(encrypted_data: bytes, key: bytes, iv: bytes) -> bytes`.
- `src/coursepilot/stream/parser.py` (14-01): Functions `resolve_media_playlist_url(master_content, master_url, preferred_quality) -> str`, `parse_media_playlist(media_content, media_url) -> StreamInfo`, `parse_stream_manifest(content, base_url, preferred_quality) -> tuple[str, StreamInfo]`.

## Flagged assumptions (spec-less fallback)

- **VDL-01 probe (unclassified):** Coursemos streaming servers may serve TS segments whose payload lengths are naturally a multiple of 16 bytes, causing PKCS7 unpadding to fail with `ValueError("Invalid padding bytes")` or return unpadded data. `decrypt_aes_128_segment` catches `ValueError` during unpadding and gracefully returns the decrypted bytes to prevent premature download aborts.

           - Build `StreamSegment(uri=..., duration=seg.duration, sequence_number=..., key_info=...)`.

         - Write to `temp_target = target_file.with_suffix(target_file.suffix + ".tmp")` (Decision D-14-12).

         - `__init__(self, client: httpx.Client | None = None, max_workers: int = 6, settings: Settings | None = None)`:
           - Default `max_workers = 6` (Assumption A-14-01).
           - Client fallback: if `client` is None, instantiate authenticated client via `get_authenticated_httpx_client(settings)` (Decision D-14-14).
           - Initialize thread-safe `_key_cache: dict[str, bytes]` with `threading.Lock()` (Pitfall 2).
         - `_fetch_key(self, key_uri: str) -> bytes`:
           - If `key_uri in self._key_cache`, return cached bytes.
           - Fetch via `self.client.get(key_uri, timeout=15.0)`. Validate response 200 and length == 16 bytes. Store in cache and return.
         - `_download_single_segment(self, segment: StreamSegment, cache_dir: Path, retry_count: int = 3) -> Path`:
           - Target path `seg_path = cache_dir / f"seg_{segment.sequence_number:06d}.ts"`.
           - Retry loop up to `retry_count`:
             - Attempt `self.client.get(segment.uri, timeout=30.0)`.
             - If `segment.key_info`:
               - Fetch key bytes via `_fetch_key(segment.key_info.uri)`.
               - IV: use `segment.key_info.iv` if present, else `derive_implicit_iv(segment.sequence_number)` (Decision D-14-06).
               - Decrypt data via `decrypt_aes_128_segment(resp.content, key, iv)`.
             - Else: data = `resp.content`.
             - Write data to `seg_path`. Return `seg_path`.
             - On HTTP error or timeout: if attempt < retry_count, sleep `2 ** (attempt - 1)` seconds (1s, 2s, 4s) and retry (Decision D-14-15). If all attempts exhausted, raise `VodDownloadError`.
         - `download_stream(self, stream_info: StreamInfo, target_file: Path, overwrite: bool = False, on_progress: Callable[[DownloadProgress], None] | None = None) -> tuple[Path, int, bool]`:
           - If `target_file.exists()` and not `overwrite`:
             - Return `(target_file, target_file.stat().st_size, True)` (Decision D-14-11).
           - Direct MP4: if `stream_info.is_direct_mp4`:
             - Stream directly to `target_file.with_suffix(".mp4.tmp")`, update progress, and atomically rename to `target_file`.
           - Cache dir setup: `cache_dir = target_file.parent.parent / ".cache" / f"stream_{uuid.uuid4().hex[:8]}"` on same volume (Pitfall 4, Assumption A-14-04).
           - Ensure `cache_dir.mkdir(parents=True, exist_ok=True)`.
           - Dispatch segment downloads using `concurrent.futures.ThreadPoolExecutor(max_workers=self.max_workers)`:
             - Map each segment to `_download_single_segment`.
             - As futures complete: update `current_segment`, calculate `percent`, and trigger `on_progress(DownloadProgress(...))` (Decision D-14-16).
           - Assemble segments in sorted order using `assemble_ts_segments_atomic(segment_paths, target_file)`.
           - Clean up `cache_dir` in `finally:` block via `shutil.rmtree(cache_dir, ignore_errors=True)`.
           - Return `(target_file, target_file.stat().st_size, False)`.
