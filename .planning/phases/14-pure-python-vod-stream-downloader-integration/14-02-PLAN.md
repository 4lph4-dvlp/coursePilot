# Plan 14-02: Playwright Stream Sniffer, Watch Concurrent Downloader & Standalone CLI Integration

## Context & Objectives

Phase 14 delivers end-to-end integration of the pure-Python streaming downloader into CoursePilot's operational workflows (VDL-02):
1. 하이브리드 스트림 스니퍼: Playwright `page.on("response")` 응답 인터셉트 및 DOM `<video>` 속성 fallback을 결합하여 `@videojs/http-streaming` blob 환경에서도 원본 m3u8 스트림 주소를 2~3초 내에 신뢰성 있게 포착.
2. 플레이어 연동: `VodPlayer.play_vod`에 `on_stream_detected` 훅을 통합하여 기존 이어보기 모달 및 진도 하트비트 루프의 중단 없이 스트림 감지 지원.
3. `watch --download` 파이프라인: 1.0배속 출석 인정 하트비트를 유지하는 동시에 백그라운드 데몬 스레드에서 최대 대역폭으로 세그먼트를 병렬 다운로드. 다운로드 실패 시에도 출석 인정은 100% 완료되도록 완벽한 오류 격리 보장 (D-14-04).
4. `download-vod` 단독 서브커맨드: 출석 1.0배속 대기 없이 영상만 고속으로 로컬 소장할 수 있는 단독 파이프라인 구축 (이미 수강 완료된 강의 포함 지원).
5. CLI 명령어 확장: `--download`, `--quality`, `--output-dir`, `--overwrite`, `--dry-run`, `--json` 지원 및 Rich 진행 표시(stderr) / 기계 가독 JSON(stdout) 분리.

## Artifacts this phase produces

- `src/coursepilot/stream/sniffer.py` (14-02): Class `StreamSniffer(on_stream_detected=None, timeout=15.0)` with methods `attach(page)`, `detach(page)`, `wait_for_stream(page, timeout=None)`.
- `src/coursepilot/stream/runner.py` (14-02): Function `run_vod_download_pipeline(course_query, week_query="current", video_index=None, preferred_quality="best", output_dir=None, overwrite=False, dry_run=False, relogin=False, headful=False, settings=None, progress_callback=None) -> VodDownloadRunResult`.
- `src/coursepilot/player/vod_player.py` (14-02): Extended `play_vod` with parameter `on_stream_detected: Callable[[str], None] | None = None`.
- `src/coursepilot/player/runner.py` (14-02): Extended `watch_course_vods` with `download: bool = False`, `preferred_quality: str = "best"`, `overwrite: bool = False`, `output_dir: Path | str | None = None`.
- `src/coursepilot/cli.py` (14-02): Added `--download`, `--quality`, `--output-dir`, `--overwrite` to `watch_group`; added `download-vod` command.
- Tests: `tests/test_stream_sniffer.py`, `tests/test_watch_download.py`, `tests/test_cli_download_vod.py`.

## Flagged assumptions (spec-less fallback)

- **VDL-02 probe (concurrency):**
  - **Attendance Isolation Guarantee:** Background segment downloading is executed in a dedicated daemon thread. Any network timeouts, HTTP 500 errors, or decryption faults log a warning on `WatchResult.error_message` and NEVER terminate or break the main thread's Video.js playback or Coursemos heartbeat loop.
  - **Atomic File Guarantee:** All segment caching and TS concatenation occur in `.cache` located on the same volume as the target file. The destination `.mp4` is replaced only when 100% of segments succeed. If aborted, incomplete files are unlinked.
  - **Re-study Video Inclusion:** The standalone `download-vod` command targets all lectures for the requested week (including completed lectures) by default, while `watch` remains strictly scoped to unwatched lectures.

           - Stores callback, timeout, `self.detected_url: str | None = None`, `self._event = threading.Event()`, `self._listener: Callable | None = None`.
         - `attach(self, page: Page) -> None`:
           - Define `_on_response(response: Response) -> None`:
             - Extract `url = response.url`.
             - Check if `".m3u8"` in url or `response.headers.get("content-type", "").startswith("application/vnd.apple.mpegurl")` or (`".mp4"` in url and "blob:" not in url and not url.endswith((".js", ".css", ".png", ".jpg"))).
             - If match and not `self._event.is_set()`:
               - `self.detected_url = url`
               - `self._event.set()`
               - If `self.on_stream_detected`:
                 - Safely dispatch `self.on_stream_detected(url)` in non-blocking try/except.
           - `self._listener = _on_response`
           - `page.on("response", _on_response)`
         - `detach(self, page: Page) -> None`:
           - If `self._listener`:
             - `page.remove_listener("response", self._listener)`
             - `self._listener = None`
         - `wait_for_stream(self, page: Page, timeout: float | None = None) -> str | None`:
           - Wait on `self._event.wait(timeout=timeout or self.timeout)`.
           - If detected, return `self.detected_url`.
           - Fallback DOM probe (Decision D-14-13):
             - `dom_src = page.evaluate("() => { const v = document.querySelector('video'); return v ? (v.currentSrc || v.src) : null; }")`
             - If `dom_src` and not `dom_src.startswith("blob:")`:
               - `self.detected_url = dom_src`
               - `self._event.set()`
               - Return `self.detected_url`
           - Return `None`
         - Provide `__enter__` and `__exit__` context manager methods for automatic attach and detach.
