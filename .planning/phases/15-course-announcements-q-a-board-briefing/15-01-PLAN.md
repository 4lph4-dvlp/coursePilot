# Plan 15-01: Domain Models, Coursemos Scraper, HTML-to-Markdown Text Converter & Atomic Read State Manager

## Context & Objectives

Phase 15 delivers Coursemos LXP course board parsing and interactive CLI briefing for announcements and Q&A (BRD-01, BRD-02).
Wave 1 establishes the foundational data models, HTML scrapers, text formatting utilities, and local read state persistence:
1. **도메인 모델 및 계약 정의:** 공지사항, Q&A, 첨부파일, 답변, 과목 그룹, 요약 통계 및 `schema_version: 1` JSON 계약을 충족하는 Pydantic 모델 구축.
2. **Coursemos HTML 스크래퍼:** 강좌 홈의 `ubboard` 활동 감지, 접근성(`.accesshide`) 정제, 키워드 기반 분류(`classify_board_type`), 5열/6열 가변 테이블 파싱, 비밀글 예외 처리, `article.php` 본문/첨부파일/답변 파싱.
3. **HTML-to-Markdown 텍스트 변환기:** Moodle Atto 편집기 HTML을 터미널 가독성 높은 마크다운으로 정제하고, Windows CP949 인코딩 충돌(`\xa0`) 방지 및 1~2줄 핵심 요약 미리보기 생성.
4. **원자적 로컬 읽음 상태 관리자:** `.cache/board_read_state.json` 파일에 열람한 글 ID를 기록하고, 임시 파일 치환(`.tmp` -> replace) 원자적 저장 및 과목당 200개 LRU 보관 상한 적용.

## Artifacts this phase produces

- `src/coursepilot/board/__init__.py`: Package exports for `coursepilot.board`.
- `src/coursepilot/board/models.py`: Pydantic models for domain entities and versioned JSON contract (`schema_version: 1`).
- `src/coursepilot/scraper/board_parser.py`: Coursemos board module discovery, list parsing, and article detail extraction.
- `src/coursepilot/board/text_converter.py`: BeautifulSoup AST-based HTML-to-Markdown converter and summary preview extractor.
- `src/coursepilot/board/read_state.py`: Thread-safe, atomic local read state manager (`board_read_state.json`) with per-course LRU 200 capping.
- `tests/test_board_parser.py`: Unit tests for HTML board scraping across 5-column, 6-column, and article detail fixtures.
- `tests/test_board_text_converter.py`: Unit tests for Markdown transformation, CP949 safety, and summary previews.
- `tests/test_board_read_state.py`: Unit tests for atomic state lifecycle, LRU 200 capping, and corrupted file recovery.
