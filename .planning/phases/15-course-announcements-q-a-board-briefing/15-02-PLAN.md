# Plan 15-02: Board Runner Pipeline, Rich Console Presentation, CLI Commands & JSON Contract

## Context & Objectives

Phase 15 delivers Coursemos LXP course board parsing and interactive CLI briefing for announcements and Q&A (BRD-01, BRD-02).
Wave 2 builds on the Wave 1 data models, scrapers, and read state manager to deliver the complete execution pipeline, Rich terminal UI, and CLI interface:
1. **수집 파이프라인 및 단독 뷰어 (`board/runner.py`):** 다중 과목 순회, 과목 단위 예외 격리(`try-except`), 트래픽 최소화(기본 `view.php`만 조회), 상세 전문 뷰어(`view_board_article`), 자동 읽음 처리, 필터(`--limit`, `--all`, `--unread-only`, `--unanswered`, `--my`, `--board-name`), 및 첨부파일 다운로드 연동.
2. **Rich 터미널 프레젠테이션 (`board/reporter.py`):** 요약 패널, 미활동 과목 1줄 요약(`[dim]• 과목명: 최근 공지 및 질문 없음[/dim]`), 활동 과목 테이블, 상태 뱃지(`[NEW]`, `[답변완료]`, `[답변대기]`, `[내 질문]`), 본문 요약 미리보기, 및 마크다운 전문 뷰어.
3. **Click CLI 명령어 및 JSON 계약 (`cli.py`):** 통합 명령어 `coursepilot board` 및 단독 편의 서브커맨드 `notices`, `qna` 등록, 표준 JSON 계약(`schema_version: 1`) 준수, 스트림 분리(stderr 진행로그 vs stdout 리포트/JSON), 및 종료 코드(0, 1, 2) 핸들링.
4. **종합 통합 테스트 (`test_board_runner.py`, `test_cli_board.py`):** 옵션 조합, 예외 격리, JSON 계약 검증, 및 CLI 러너 통합 검증.

## Artifacts this phase produces

- `src/coursepilot/board/runner.py`: Orchestrator for multi-course board collection, post filtering, single article detail viewer, and attachment downloads.
- `src/coursepilot/board/reporter.py`: Rich Console rendering for board summary panels, course tables, status badges, and article markdown viewer.
- `src/coursepilot/reporter.py`: Integration and re-export of `render_board_report` and `render_article_viewer`.
- `src/coursepilot/cli.py`: Click CLI commands `@cli.command("board")`, `@cli.command("notices")`, `@cli.command("qna")`.
- `tests/test_board_runner.py`: Integration tests for `run_board_pipeline`, `view_board_article`, filter logic, and course error isolation.
- `tests/test_cli_board.py`: CLI integration tests for `board`, `notices`, `qna`, `--json` contract, exit codes, and option routing.
