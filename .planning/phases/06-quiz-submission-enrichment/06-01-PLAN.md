<objective>
Fix quiz submission status detection when grades are hidden by the instructor.

Purpose: In KAU LXP courses like 기초전자실험, quiz grades are kept blank (`''`) in the general quiz index table (`/mod/quiz/index.php?id=...`). The current parser marks these quizzes as `NOT_ATTEMPTED`, causing already-taken quizzes to appear as `OVERDUE` once deadlines pass. This plan introduces quiz view page (`/mod/quiz/view.php?id=...`) inspection to detect attempt completion (e.g., "답안 검토", "응시 가능 횟수를 초과하여 더 이상 응시할 수 없습니다.", "완료됨") and mark them as `SUBMITTED`.
</objective>
